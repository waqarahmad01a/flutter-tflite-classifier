# Flutter TFLite Image Classifier

A production-ready Flutter sample app demonstrating TensorFlow Lite (TFLite) image classification with GetX state management and clean architecture.

## Features
- On-device image classification using TensorFlow Lite.
- Image selection from Camera and Gallery (`image_picker`).
- Reactive state management using GetX.
- Clean separation of concerns (Services, Controllers, Views).

## Tech Stack
- **Framework:** Flutter (Dart)
- **State Management:** GetX
- **AI / ML:** TensorFlow Lite (`tflite_flutter`)
- **Media:** Image Picker
